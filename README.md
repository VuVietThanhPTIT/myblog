# VuVietThanh Blog

Personal blog built with [Hugo](https://gohugo.io/) and [Hugo Theme Stack](https://github.com/CaiJimmy/hugo-theme-stack), deployed to GitHub Pages at <https://vuvietthanhptit.github.io/myblog/>.

## Quick Reference

- **Site title & URL**: `config/_default/config.toml`
- **Sidebar bio, avatar, theme options**: `config/_default/params.toml`
- **Social links & menu**: `config/_default/menu.toml`
- **Avatar & favicon images**: `assets/img/avatar.png` and `assets/img/favicon.png`
- **Blog posts**: create a folder under `content/post/<post-slug>/` with `index.md` and local images.
